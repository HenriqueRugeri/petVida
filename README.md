# PetVida

Sistema digital desenvolvido para a Clínica PetVida, com o objetivo de modernizar a gestão de agendamentos, facilitar o acesso às informações dos pacientes e melhorar a experiência dos tutores e da equipe veterinária.
A solução consiste em um site com html e css que junta as informações necessárias sobre o tutor, animal, horarios disponiveis e o tipo de atendimento, projetado para atender às necessidades operacionais da Clínica PetVida.

Projeto desenvolvido para a disciplina Design Profissional, como atividade prática individual baseada no estudo de caso da Clínica PetVida & Estética Animal.

Docente: Prof. Sedenilso Antonio Machado.
